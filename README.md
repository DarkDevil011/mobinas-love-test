# Mobina’s Love Test 💗

یک بازی عاشقانه‌ی فارسی و واکنش‌گرا با ۵ سؤال، نوار عشق و پیشنهاد رابطه. نتیجه پس از انتخاب پاسخ نهایی، از طریق Netlify Function به ربات تلگرام ارسال می‌شود.

## ساختار پروژه

```text
.
├── index.html
├── styles.css
├── app.js
├── netlify.toml
├── package.json
└── netlify/
    └── functions/
        └── submit-result.js
```

## پیش‌نیازها

- حساب رایگان Netlify
- ربات تلگرام ساخته‌شده از طریق BotFather
- Node.js نسخه ۱۸ یا جدیدتر برای اجرای محلی
- دسترسی ربات به گفت‌وگو با صاحب سایت

## اتصال تلگرام

1. در تلگرام وارد گفت‌وگوی ربات خودتان شوید و حداقل یک‌بار `/start` بفرستید. ربات نمی‌تواند بدون شروع گفت‌وگو از طرف کاربر به او پیام خصوصی بدهد.
2. توکن ربات را از BotFather بردارید. **نام کاربری ربات به‌تنهایی کافی نیست؛ این پروژه به Bot Token نیاز دارد.**
3. در Netlify وارد سایت شوید: **Site configuration → Environment variables**.
4. این دو متغیر را اضافه کنید:
   - `TELEGRAM_BOT_TOKEN` = توکن محرمانه‌ای که BotFather داده است
   - `TELEGRAM_CHAT_ID` = `1299051837`
5. پس از ذخیره متغیرها، سایت را دوباره Deploy کنید تا Function متغیرهای جدید را دریافت کند.
6. برای تست، لینک منتشرشده را باز کنید، پنج سؤال را پاسخ دهید و در پایان یکی از دو پاسخ پیشنهاد رابطه را انتخاب کنید. پیام باید به چت مقصد برسد.

**امنیت:** توکن را هرگز در `app.js`، HTML، مخزن عمومی Git یا پیام‌های قابل مشاهده بازدیدکننده قرار ندهید. اگر توکن قبلاً جایی منتشر شده، از BotFather آن را باطل و توکن جدید ایجاد کنید.

## انتشار رایگان روی Netlify

### روش ساده با GitHub

1. فایل‌های این پروژه را در یک مخزن GitHub قرار دهید.
2. در Netlify گزینه **Add new site → Import an existing project** را انتخاب کنید.
3. مخزن را متصل کنید.
4. تنظیمات Build:
   - Build command: خالی
   - Publish directory: `.`
   - Functions directory: `netlify/functions` (در `netlify.toml` تنظیم شده)
5. سایت را Deploy کنید. Netlify یک آدرس رایگان شبیه `https://your-site-name.netlify.app` می‌دهد.
6. متغیرهای محیطی تلگرام را طبق بخش قبل تنظیم و دوباره Deploy کنید.

### اجرای محلی

```bash
npm install
npx netlify dev
```

برای ارسال واقعی تلگرام در اجرای محلی، متغیرها را در محیط ترمینال تنظیم کنید یا فایل `.env` محلی بسازید (این فایل را commit نکنید):

```env
TELEGRAM_BOT_TOKEN=توکن_ربات
TELEGRAM_CHAT_ID=1299051837
```

سپس `npx netlify dev` را اجرا کنید.

## رفتار و حریم خصوصی

- در صفحه شروع، پیش از شروع بازی، به مبینا گفته می‌شود که پاسخ‌ها و نتیجه پس از تکمیل برای سازنده ارسال می‌شوند.
- ارسال فقط بعد از انتخاب یکی از دو پاسخ پیشنهاد رابطه انجام می‌شود.
- انتخاب «بذار بیشتر فکر کنم» کاملاً معتبر است و هیچ فشاری برای پذیرش وجود ندارد.
- پاسخ‌ها تا پایان تست در حافظه همان صفحه نگهداری می‌شوند؛ با رفرش صفحه، تست از ابتدا شروع می‌شود.
- توکن و Chat ID فقط در Function سمت سرور خوانده می‌شوند.
- برای جلوگیری از ارسال مجدد یک درخواست با همان شناسه، از Netlify Blobs استفاده شده است. این محافظ در برابر تکرار همان شناسه است؛ برای سامانه‌های پرترافیک یا تضمین سخت‌گیرانه‌ی exactly-once، صف و ذخیره‌سازی تراکنشی اختصاصی لازم است.
